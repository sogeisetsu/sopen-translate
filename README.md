# sopen-translate

一个轻量的浏览器翻译插件：选中或整页翻译网页内容，翻译能力由用户自己配置的 API 密钥驱动，可接入多种翻译服务。

## 目标

- 整页翻译 + 划词翻译，尽量不打断原页面结构
- 多后端可切换（OpenAI 兼容接口、DeepL、Google、自建服务等）
- API 密钥保存在浏览器本地，不上传、不进仓库
- 设置页可管理多个密钥配置、测试连通性、设定默认服务

## 设计约束

- Manifest V3
- 无后端：所有请求由扩展直接发往用户配置的服务地址
- 密钥只存 `chrome.storage.local`，不写日志、不随导出泄露
